# Hyde capability matrix

Updated 2026-10-21. **Implemented** means code exists; **Integrated** means it is reachable in the product; **Verified** means the relevant workflow has been exercised. The complete target remains [PLAN.md](PLAN.md).

Checkpoint: 265 unit tests pass across 42 files; the production editor/player build and focused Chrome reflow/font/microphone workflows pass. Earlier focused Chrome cases cover scene editing/alignment, audio preview and tails, world-point rotation, editable paths, text animation, media pinning and placement, procedural motion, assembly gap/mix/key/master editing, fonts, archives, directory libraries, and isolated web output.

Architecture: React editor controls call reusable TypeScript project operations; one deterministic evaluator and Pixi renderer drive editor, player, and frame export. `.hyde` and `.hy` are equivalent ZIP/XML project archives; `.hyproj` is a self-contained assembly archive. Recovery is browser-private (large assets in OPFS with IndexedDB fallback); exports are independent static packages, including `file://` playback. Web Audio owns live time, with bounded effect-history reconstruction and finite tails. Render optimization is a hint only; cached visuals invalidate on project, evaluated pose, texture, and font changes. No backend or accounts.

Open work: physical microphone latency/offset measurement; broader text and export appearance coverage; sustained export/render memory and performance; storage-exhaustion recovery; target-browser, accessibility, and deployment checks. The portable IIFE build still emits `import.meta` warnings, although tested playback paths run. Create the richer primary showcase only after the planned capabilities are substantially complete, retaining the current example as secondary. [PLAN.md](PLAN.md) remains the scope authority.

Next priorities: check sustained export/render performance and memory, storage-exhaustion recovery, and broader visual/audio export fidelity; then target-browser, accessibility, and deployment checks before the primary showcase.
