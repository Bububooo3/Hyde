Checkpoint: 285 unit tests across 48 files and the production editor/portable-player build pass. The full 111-test Chrome suite passed before the Web Audio fallback, followed by focused delayed-image/video and live-tone offset checks; the delayed-image check also passes in Playwright WebKit. Edge, WebKit and native Firefox smoke passed earlier. The portable IIFE build still emits `import.meta` warnings, although tested playback works.

Architecture: React editor controls call reusable TypeScript project operations; one deterministic evaluator and Pixi renderer drive editor, player, and frame export. `.hyde` and `.hy` are equivalent ZIP/XML project archives; `.hyproj` is a self-contained assembly archive. Recovery is browser-private (large assets in OPFS with IndexedDB fallback); exports are independent static packages, including `file://` playback. Web Audio owns live time when available, with bounded effect-history reconstruction and finite tails; a monotonic visual clock keeps silent playback possible without it. Render optimization is a hint only; cached visuals invalidate on project, evaluated pose, texture, and font changes. No backend or accounts.

Open work: direct browser checks for specialized timeline snapping and attachment anchors; physical mobile viewing, longer export and real-GPU performance; screen-reader review, real Safari, physical microphone latency/listening, live UIUC hosting, and owner showcase review. [PLAN.md](PLAN.md) remains the scope authority.
