Checkpoint: 280 unit tests across 46 files and the production editor/portable-player build pass. The 101-test Chrome suite passed before the final stage-guide/Alt routing additions; focused motion, timeline, stage-guide, stage and interface browser checks passed after them. Edge, WebKit and native Firefox smoke pass. The portable IIFE build still emits `import.meta` warnings, although tested playback works.

Architecture: React editor controls call reusable TypeScript project operations; one deterministic evaluator and Pixi renderer drive editor, player, and frame export. `.hyde` and `.hy` are equivalent ZIP/XML project archives; `.hyproj` is a self-contained assembly archive. Recovery is browser-private (large assets in OPFS with IndexedDB fallback); exports are independent static packages, including `file://` playback. Web Audio owns live time, with bounded effect-history reconstruction and finite tails. Render optimization is a hint only; cached visuals invalidate on project, evaluated pose, texture, and font changes. No backend or accounts.

Open work: stale-revision clip draft recovery and editing guards; direct browser checks for specialized timeline snapping and attachment anchors; preview/export text, masks, nested scenes, effects and beep/flash synchronization; throttled player buffering, missing fonts/unsupported media and mobile viewing; longer export and real-GPU performance; screen-reader review, real Safari, physical microphone latency/listening, and live UIUC hosting. The richer primary showcase is still to be made; retain the current example as secondary. [PLAN.md](PLAN.md) remains the scope authority.

Next priorities: fix stale draft recovery, then run integrated visual/audio fidelity and failure-path fixtures, followed by the primary showcase and remaining platform checks.
